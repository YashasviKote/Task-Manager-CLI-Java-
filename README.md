# Task Manager CLI (Java)

## Description
A command-line based task manager application built using Java.  
It supports full task lifecycle management with persistent storage.

## Features
- Add tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Search tasks by keyword
- Filter completed tasks
- Persistent storage using file system
- Input validation and error handling

## Tech Stack
- Java
- Collections Framework
- Streams API
- File Handling
